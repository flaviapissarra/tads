# Atividade Avaliativa 2 - Semana 5

1. Qual das opções mostra corretamente a sequência Entrada → Processamento → Saída em um programa que calcula a soma de dois números? A. Ler dois números → Calcular a soma → Mostrar o resultado.
2. Em C, qual a forma correta de declarar uma constante inteira chamada MAX com valor 100? C. #define MAX 100
3. O que significa o fluxo Entrada → Processamento → Saída? C. A ordem lógica em que um programa recebe dados, realiza cálculos e apresenta resultados.
4. O que é uma variável em programação? C. Um espaço na memória que pode armazenar valores que variam durante a execução.
5. Qual a principal característica de uma variável local declarada com static dentro de uma função? A. Mantém o valor mesmo após finalizado o seu escopo.
