# Atividade Avaliativa 1 - Semana 3

1. O pseudocódigo pode ser definido como: D. Uma descrição estruturada de um algoritmo, próxima da linguagem de programação, mas sem regras rígidas.
2. Em um fluxograma, qual símbolo é utilizado para representar decisões (condições)? D. Losango.
3. O que é um algoritmo? A. Um conjunto de passos ordenados e finitos para resolver um problema.
4. Qual é a principal diferença entre linguagem natural e pseudocódigo na representação de algoritmos? B. A linguagem natural pode gerar ambiguidades; o pseudocódigo é mais estruturado e próximo de uma linguagem de programação.
5. Qual das opções abaixo NÃO é uma vantagem de representar um algoritmo antes de programá-lo? C. Garantir que o computador execute o algoritmo de forma rápida.
