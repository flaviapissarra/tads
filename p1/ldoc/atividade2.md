# Conceitos de sistemas de numeração, conversão de bases e aritmética binária

1. Qual é a característica principal de um sistema de numeração posicional? b. O valor de um dígito é determinado por sua posição;
2. No sistema hexadecimal, qual é o valor decimal do dígito 'E'? d. 14;
3. O número decimal 45, quando convertido para a base binária, é igual a: a. $(101101)_{2}$;
4. O número binário $(1101)_{2}$, quando convertido para a base decimal, é igual a: c. 13;
5. O número hexadecimal $(2A)_{16}$, quando convertido para a base decimal, é igual a: c. 42;
> 6. O número binário [ $(1101101)_{2}$ ], quando convertido para a base octal, é igual a: a. [ $(155)_{8}$ ]
7. Qual é o resultado da soma binária [ $(1011)_{2}$ ] ​+ [ $(110)_{2}$ ]? a. [ $(10001)_{2}$​ ]
