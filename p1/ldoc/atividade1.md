# Sistemas de Computação

1. Explique com suas palavras o que é um sistema de computação e quais são os principais elementos que fazem parte dele.

> Um sistema de computação pode ser definido como um conjunto de componentes integrados (CPU, memórias, componentes E/S) que funcionam como um elemento único que tem objetivo manipular dados e obter informações úteis a partir deles.

2. Qual é a função do processador (CPU) em um computador? Explique por que ele é considerado um dos principais componentes do sistema.
> O processador é um dos principais componentes do sistema porque é o componente que lê e interpreta instruções de máquina e realiza operações (matemáticas ou outras definidas pós interpretação); é através dele que o computador executa um ciclo básico de instrução: busca a instrução na memória -> a interpreta -> a executa.

3. Explique a diferença entre memória RAM e armazenamento (HD ou SSD). Dê um exemplo de situação em que cada um deles é utilizado.
> Enquanto a memória RAM (física e virtual) representa um armazenamento temporário dentro do sistema de computador, o HD ou o SSD representam armazenamentos permanentes. A RAM é volátil, e essa memória é utilizada para guardar dados temporários que precisam ser processados imediatamente por programas abertos, sendo eles apagados quando se desliga o computador; já os HDs e o SSDs são memórias que servem para armazenar dados de arquivos e S.O.s de forma permanente.

4. O que é um sistema operacional? Explique sua importância para o funcionamento do computador e cite dois exemplos de sistemas operacionais.
> Um sistema operacional é um conjunto de instruções armazenados em um HD ou SSD que têm por objetivo gerenciar os recursos de hardware do computador, servindo como uma espécie de "ponte". São os SOs que organizam como a máquina vai funcionar, quais instruções precisa executar e em qual ordem precisa executá-las. Em resumo: ele gerencia processos, memórias, faz controle de hardware e fornece uma interface com o(a) usuário(a). Dois exemplos de SOs são Ubuntu (Linux) e Windows 10 (Windows).

5. Imagine que um computador está muito lento quando vários programas estão abertos ao mesmo tempo. Quais componentes ou recursos do sistema podem estar relacionados a esse problema? Explique sua resposta.
> Provavelmente a capacidade da memória RAM não acompanha a quantidade necessária para o processamento concorrente de tantos processos que o SO está tentando gerenciar, assim, o sistema tenta recorrer à memória secundária (que é mais lenta, causando travamentos por conta da discrepância de velocidade entre elas), o que explicaria tal lentidão.
